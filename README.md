# 📚 Refika – Quranic Arabic Learning Assistant

**Refika** is a mobile app designed to help Turkish-speaking learners master **Quranic Arabic** through gamified, interactive learning activities. It aims to make learning enjoyable, consistent, and aligned with traditional teaching methods.

## 🚀 Features (Phase 1)

- 🧠 **Matching Games** – Match Arabic words with their Turkish meanings  
- ✋ **Drag-and-Drop Exercises** – Practice grammar and sentence structure  
- 🎯 **Quizzes** – Multiple-choice questions with instant feedback  
- ❤️ **Heart System** – Lose hearts for wrong answers, earn points for correct ones  
- 🏅 **Visual Feedback** – Fun animations for correct and incorrect answers  

## 🔜 Roadmap (Phase 2)

- 🔐 User authentication and profiles  
- 📊 Progress tracking and level system  
- 🏆 Leaderboard for competitive learning  
- 📅 Daily challenges and habit-forming mechanics  
- 📚 Modular content aligned with specific textbooks  

## 🛠️ Tech Stack

- **React Native (Expo)** – Cross-platform mobile development  
- **Firebase** – Backend, authentication, and data storage (Phase 2)  
- **Hugging Face API** – AI-powered language and image recognition (advanced stages)

## 👩‍🏫 Educational Foundation

Refika is based on the teaching methodology of **Fatma Serap Karamollaoğlu**, a respected educator in Quranic Arabic. The app is designed to work in harmony with her materials and curriculum.
